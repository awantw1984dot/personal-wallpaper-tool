Personal Wallpaper Tool

Personal Wallpaper Tool is a private personal project created for testing and learning purposes.

The application is designed to connect to my own Pinterest account, read selected Pinterest boards, retrieve image information from Pins, and use those images as wallpapers on my personal iPhone through Apple Shortcuts.

Purpose

The main purpose of this project is to explore and test:

  • Pinterest API integration
  • Reading my own Pinterest boards and Pins
  • Retrieving image URLs from authorized Pinterest content
  • Apple Shortcuts automation
  • Automatic wallpaper selection and updating on my personal iPhone

Personal Use Only

Personal Wallpaper Tool is not a commercial product, public service, wallpaper application, or content distribution platform.

It is intended only for my own personal use and development testing.

The application does not provide Pinterest content to other users and does not resell, redistribute, or commercially exploit Pinterest data.

Pinterest Access

The application only accesses Pinterest data that has been authorized by the Pinterest account owner through the permissions granted to the application.

Pinterest API data is used only to support the personal wallpaper automation workflow.
