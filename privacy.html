Privacy Policy

Effective Date: October 24, 2026

This Privacy Policy describes how Personal Wallpaper Tool handles information when accessing Pinterest through the Pinterest API.

1. Purpose of the Application

Personal Wallpaper Tool is a private application created for personal testing, learning, and Apple Shortcuts automation.

The application is used to access my own Pinterest boards and Pins and retrieve image information for use as wallpapers on my personal iPhone.

The application is not offered as a public or commercial service.

2. Information Accessed

Personal Wallpaper Tool may access information made available through the Pinterest API according to the permissions authorized by the Pinterest account owner.

This may include:

  • Pinterest account information required for API authentication
  • Pinterest boards
  • Pins contained in authorized boards
  • Pin titles, descriptions, links, and image information
  • Other Pinterest data made available through the approved API permissions

The application only accesses data necessary for its intended personal functionality.

3. How Information Is Used

Pinterest data is used only to:

  • Identify authorized Pinterest boards and Pins
  • Retrieve image URLs or related image information
  • Select images for use as personal iPhone wallpapers
  • Test Pinterest API and Apple Shortcuts integration

Pinterest data is not used for advertising, profiling, analytics, resale, or commercial purposes.

4. Data Sharing

Personal Wallpaper Tool does not sell, rent, trade, or share personal information or Pinterest account data with third parties.

Pinterest data is not distributed to other users.

5. Data Storage

Personal Wallpaper Tool is designed for personal use.

API credentials, access tokens, and retrieved Pinterest data may be temporarily processed on the project owner's personal devices as required for the application to function.

No public database of Pinterest user information is maintained.

6. Access Tokens and Credentials

Pinterest access tokens and API credentials are used only to authenticate requests to the Pinterest API.

These credentials are not intentionally published or shared with third parties.

7. Data Retention

Pinterest data is retained only when necessary for testing or personal automation.

Temporary data may be removed when it is no longer required.

The application does not maintain long-term user profiles or behavioral tracking databases.

8. Third-Party Services

Personal Wallpaper Tool uses the Pinterest API.

Use of Pinterest services is also subject to Pinterest's own terms, policies, and privacy practices.

9. User Control

The Pinterest account owner can revoke the application's access through Pinterest account settings or related authorization controls.

Revoking access will prevent the application from making further authorized Pinterest API requests.

10. Changes to This Privacy Policy

This Privacy Policy may be updated if the functionality of Personal Wallpaper Tool changes.

Any updated version will be published on the same public page.
